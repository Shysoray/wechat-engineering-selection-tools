# APTech 系列确认矩阵

更新日期：2026-07-17

## 判定原则

- 绿色：系列、压力、Cv/流量状态、材质、接口和选项均落入已确认范围，且输入没有未识别扩展字段。
- 琥珀色：存在唯一候选，但仍有明确字段或系列边界需要确认。
- 禁止确定：存在压力覆盖、等效范围或系列归属风险，不能直接复制为确定型号。
- 模糊匹配始终保持琥珀色，不因系列已确认而放行。

## 输入完整性

已确认系列出现客户特殊号、未知后缀或未识别 token 时，结果自动降为琥珀色并显示 `未确认扩展字段`。旧页面结果在恢复时使用当前规则重新计算，不保留历史颜色。

AP/AZ 调压阀中可明确解析的结构化输入，如果使用系列基号、无效压力档、缺少流路或接口数量不完整，必须直接返回“未识别”且不提供任何模糊候选。OCR 字符混淆等无法结构化解析的输入，才允许进入低置信度查找。

其它可明确解析为 `AP/AZ + 数字型号` 的订货号，如果未命中目录、归一化或生成规则，同样禁止进入全库跨型号模糊搜索。隔膜阀仅保留已限定在同系列且接口硬字段一致的专用候选逻辑。
